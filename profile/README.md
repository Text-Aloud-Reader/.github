## Understanding Text Aloud Reader Core Components

- **Chapter** - the document you already saved and are allowed to hear.
- **Voice** - the TextAloud choice for that file.
- **Pace** - how fast Read Text Aloud moves through a page.
- **Playback** - start, pause, and resume on the same sentence.
- **Folder** - the path you named, left where it was.
- **Take** - audio you export only when you still need it beside the chapter.
- **Profile** - your pace, kept separate from someone else's on a shared PC.

## Before and After Text Aloud Reader

**Before Text Aloud Reader**  
The chapter is saved, but playback lives somewhere else, and you cannot tell which clip still matches the file.

**After Text Aloud Reader**  
TextAloud sits with the document, Read Text Aloud starts from that same path, and the original stays put.

## Closing Notes for Text Aloud Reader

Treat Text Aloud Reader as a way to hear a file, not as a second copy of your library. Open TextAloud when the chapter is the one you meant. Keep the working set small. Move a finished take out of the source folder when you no longer need it beside the text. Let older audio stay quiet.

If you change rooms, reopen the same folder. If you show someone Read Text Aloud, show them the file first. After that, Text Aloud Reader usually needs almost no explanation.

## Quick Start with Text Aloud Reader

1. **Open Text Aloud Reader** - Confirm the voice and the folder you named.
2. **Load the chapter** - Point TextAloud at a document you are allowed to keep.
3. **Play one page** - Check Read Text Aloud on a short span first.
4. **Set the pace** - Slow down only where the sentences pile up.
5. **Leave the source** - Do not move the original just to hear it.
6. **Optional take** - Save audio beside the file if you need it later.
7. **Reopen** - Next time, start from that same Text Aloud Reader document.

## Why This Exists

Most listening sessions separate the chapter from the player, so you stop trusting which words you heard. **Text Aloud Reader** keeps the document and the voice together.

Text Aloud Reader solves **one specific problem**: a file you already saved and still need to hear. Open it in TextAloud, press play, and let Read Text Aloud follow the page you named.

If you are tired of matching clips back to documents by hand, **Text Aloud Reader** is for you.

A second pass the next morning should open the same path. The voice and the pace should still be the ones you set. The original chapter should still be the file you filed, not a renamed copy you cannot place.
